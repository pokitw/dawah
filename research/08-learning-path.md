# 08 — Learning Path

## Level 1 — Foundations (Beginner)
**Goals:** Understand the basic words; give one clear argument; know the adab.
- Module 1.1: Glossary + valid vs sound (file 00, 04).
- Module 1.2: ARG-1 (Quran 52:35) and OBJ-6 (who created God).
- Module 1.3: Dawah adab (file 05) + finding the root of doubt.
- **Checkpoint:** Roleplay P1 (Sara) and score ≥ 18/30.

## Level 2 — Core Arguments (Intermediate)
**Goals:** Use kalam, morality, fitrah; steelman.
- Module 2.1: ARG-2 (kalam) + OBJ-11 (objections).
- Module 2.2: ARG-5 (morality) + OBJ-4 (Euthyphro) + OBJ-7.
- Module 2.3: ARG-4 (fitrah) + steelmanning practice (file 04).
- **Checkpoint:** Roleplay P2 (Rick) and P8 (James), score ≥ 20/30.

## Level 3 — Hard Questions (Advanced)
**Goals:** Handle evil, hiddenness, qadr, hell with care.
- Module 3.1: OBJ-1, OBJ-2, OBJ-3 (problem of evil, all forms).
- Module 3.2: OBJ-5 (hiddenness), OBJ-12 (qadr), OBJ-13 (hell).
- Module 3.3: Emotional dawah — P5, P7 (listen first).
- **Checkpoint:** Roleplay P7 (Maria) with adab ≥ 4/5.

## Level 4 — Expert / Science & Meaning
**Goals:** Consciousness, fine-tuning, miracles, why-Islam, nihilism.
- Module 4.1: ARG-6, ARG-7, OBJ-8, OBJ-9, OBJ-10.
- Module 4.2: OBJ-14 (why Islam), OBJ-15 (miracles), OBJ-16 (meaning).
- Module 4.3: ARG-3 (contingency, deep).
- **Checkpoint:** Roleplay P3 (Dr. Vance) and P4 (Dr. Chen), score ≥ 22/30.

## Sample Quiz Questions (MCQ with explanations)
**Q1.** The kalam argument says the universe has a cause because:
- A) Everything has a cause
- B) Whatever BEGINS to exist has a cause, and the universe began ✅
- C) Science proved God
- D) The Quran says so only
*Explain:* A is too strong (God didn't begin); the correct principle is about things that BEGIN.

**Q2.** The best answer to Euthyphro is:
- A) Good is whatever God randomly commands
- B) Good is above God
- C) Good flows from God's perfectly good nature ✅
- D) There is no good
*Explain:* C escapes both horns of the false dilemma.

**Q3.** When someone is grieving and angry at God, you should FIRST:
- A) Give the kalam argument
- B) Listen and show empathy ✅
- C) Quote many hadith fast
- D) Tell them it's just a test and move on
*Explain:* Match the answer to the ROOT (pain, not intellect).

**Q4.** "You only believe because you were born Muslim" is which fallacy?
- A) Strawman
- B) Genetic fallacy ✅
- C) Ad hominem
- D) False dilemma
*Explain:* It judges a belief by its ORIGIN, not its truth.

**Q5.** Which is an OVERCLAIM to avoid?
- A) "The universe fits a beginning"
- B) "Science has 100% proven the Quran's miracles" ✅
- C) "I don't know, let me check"
- D) "Life is a test"

## Sample Flashcards (front → back)
- Contingent → Could have not existed; depends on something else.
- Necessary being → Must exist; depends on nothing → Allah.
- Kalam → Universe began → so it has a cause.
- Fitrah → Inborn belief in God (30:30; Bukhari 1358).
- Euthyphro answer → Good flows from God's nature (not arbitrary, not above God).
- Waswas cure → Seek refuge, say "Amantu billah," stop, change activity.
- Is/ought → Can't get values from facts alone.
- Steelman → State opponent's view at its strongest first.
- 16:125 → Invite with wisdom, good preaching, best argument.
- 28:56 → You can't guide; only Allah guides.
